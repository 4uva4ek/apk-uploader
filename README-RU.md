# APK Uploader

Устанавливает APK и копирует кеш игр на **Samsung Galaxy XR** через ADB с компьютера на Windows.
Автор: **4uva4ek**.

Скачайте ZIP из [Releases](https://github.com/4uva4ek/apk-uploader/releases), распакуйте
и запустите `ApkUploader.exe`. Java и adb уже внутри, ничего устанавливать не нужно.

## Использование

1. Включите на шлеме параметры разработчика и отладку по USB, подключите кабель и подтвердите
   запрос отладки. Шлем появится в верхней панели. Для Wi-Fi откройте **Connect**: введите адрес
   (`ip:port`), выполните сопряжение по коду беспроводной отладки или переключите подключённый
   по USB шлем на Wi-Fi.
2. Перетащите в окно APK-файлы и папки с кешем (или **Add APK files** / **Add cache folder**).
   Можно бросить несколько элементов сразу; они обрабатываются по очереди.
3. Следите за очередью: прогресс и скорость загрузки, установка, результат. Для ошибок показана
   причина от менеджера пакетов, элемент можно повторить. Если установленное приложение подписано
   другим ключом или новее, **Uninstall and retry** сначала удалит его (данные приложения пропадут).

Папки кеша распознаются по содержимому ([подробности](docs/CACHE-LAYOUT.md)):
файлы `*.obb` идут в `/sdcard/Android/obb/<package>/`, папка с именем пакета — в
`/sdcard/Android/data/<package>/`, распакованная папка `Android/` зеркалируется, для
неизвестной раскладки программа спросит, куда копировать. APK из той же партии ставятся первыми.

**Updates** проверяет GitHub Releases при запуске; новая версия скачивается, проверяется по
размеру и SHA-256 и устанавливается на место, предыдущая версия сохраняется рядом с программой.

Настройки и журналы: `%LOCALAPPDATA%\ApkUploader`.

## Что меняется на шлеме

Только обычные пользовательские операции: `pm install` и копирование файлов в `/sdcard/Android`.
Системные файлы, root, прошивка и постоянные настройки не затрагиваются. Установленные
приложения и скопированный кеш остаются после перезагрузки; удаляйте их через настройки
приложений шлема или adb. Переключение на Wi-Fi использует `adb tcpip 5555`, которое шлем
забывает после перезагрузки.

## Сборка

Нужен JDK 21. Gradle скачивает закреплённую версию Android platform-tools (adb) и проверяет
её SHA-256 перед упаковкой.

```sh
./gradlew :app:test
./gradlew :app:createReleaseDistributable   # app/build/compose/binaries/main-release/app/ApkUploader
```

Процесс выпуска описан в [docs/RELEASING.md](docs/RELEASING.md).
